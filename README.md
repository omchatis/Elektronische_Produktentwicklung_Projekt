# Laserablenksystem

This repository contains the documentation, design data, and project artifacts for the Laserablenksystem. It brings together the electrical, mechanical, software, and management aspects of the project in one place.

## Repository structure

- electrical/ - PCB designs, schematics, fabrication data, and design rules
- mechanical/ - CAD files and mechanical design assets
- software/ - MCU firmware and configuration files
- projectmanagement/ - planning files such as the Gantt chart
- report/ - project reports and documentation
- specifications/ - technical specifications and requirements
- lists/ - component and part lists

## Notes

Use this repository as the central reference for hardware design, firmware development, and project planning related to the Laserablenksystem.
